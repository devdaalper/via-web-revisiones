## Regla de publicación

Mientras una revisión aún no haya sido evaluada, sus correcciones se mantienen bajo el mismo número.
Después de recibir retroalimentación formal, cualquier nueva ronda crea el siguiente número consecutivo
y una nueva carpeta inmutable.

Los nombres públicos siguen una secuencia simple (`Versión 1`, `Versión 2`, etc.). Los folios
`VIA-WEB-R###` se conservan únicamente como identificadores técnicos para garantizar la trazabilidad.
