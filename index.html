Protocolo

Así se comparte una revisión a partir de ahora.

  1. Publicar un corte inmutable.
    Cada entrega externa recibe el siguiente número R.
  2. Compartir la URL numerada.
    Nunca se envía un enlace sin identificador y estado.
  3. Asociar el feedback.
    Cada comentario cita la revisión exacta que fue observada.
